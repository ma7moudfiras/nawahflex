## نظرة سريعة

الموقع التعريفي للأكاديمية — عربي بالكامل (RTL)، متجاوب، سريع، ومهيّأ لمحركات
البحث ومشاركة الروابط على واتساب وفيسبوك. مبني بـ **HTML/CSS/JavaScript خالص**
بلا أي إطار عمل أو خطوة بناء.

| | |
|---|---|
| **الواجهة** | HTML · CSS · JavaScript (صفر اعتماديات) |
| **قاعدة البيانات** | Supabase (PostgreSQL + RLS + Storage) |
| **النشر** | Vercel |
| **إدارة الإصدارات** | GitHub |
| **المرحلة القادمة** | تطبيق Flutter للطلاب والإدارة |

---

## التشغيل محلياً

```bash
npx serve site
```

ثم افتح `http://localhost:3000`. لا حاجة لأي تثبيت — يمكنك أيضاً فتح
`site/index.html` مباشرة في المتصفح.

---

## تعديل محتوى الموقع

**كل النصوص والأرقام والبطاقات في ملف واحد:** `site/js/content.js`

```js
// مثال: تغيير رقم الواتساب
academy: {
  whatsapp: "970599000000",   // بدون + وبدون مسافات
  phone: "+970 599 000 000",
  email: "info@nawahflex.org",
}
```

المحتوى الحالي **تجريبي** وموسوم داخل الملف بـ `⚠️`. ابحث عن هذا الرمز لتصل
سريعاً إلى كل ما يحتاج استبدالاً: الأرقام، الشركاء، الأخبار، الآراء، الصور،
وروابط التواصل الاجتماعي.

لتغيير الألوان أو الخطوط: `site/css/tokens.css`.

## ربط قاعدة البيانات

**القاعدة مربوطة وتعمل.** مشروع Supabase باسم `nawahflex` في منطقة `eu-central-1`،
والميغريشن مطبّق، و`site/js/config.js` مملوء بالمفتاح العلني.

لإعادة البناء من الصفر على مشروع جديد، طبّق الميغريشن بالترتيب:

```
supabase/migrations/0001_init.sql
supabase/migrations/0002_move_helpers_to_private_schema.sql
```

ثم املأ `site/js/config.js` برابط المشروع ومفتاحه العلني.

> **ملاحظة أمنية:** المفتاح العلني مصمّم ليكون مكشوفاً في المتصفح — الحماية
> الحقيقية من سياسات RLS في الميغريشن. لا تضع `service_role` key هنا أبداً.

**السلوك:** الزائر يستطيع الإرسال فقط، ولا يقرأ الرسائل إطلاقاً. وإذا تعذّر
الوصول للقاعدة أو تجاوز الطلب ١٢ ثانية، يتحوّل النموذج تلقائياً إلى واتساب.

## النشر على Vercel

اربط المستودع بـ Vercel — الإعدادات جاهزة في `vercel.json`
(`outputDirectory: site`، بلا أمر بناء). كل دفعة إلى الفرع الرئيسي تُنشر تلقائياً.
